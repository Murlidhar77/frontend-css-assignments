# Grilled Potato Chips Landing Page

This is a product landing page I built with HTML and CSS for a fictional grilled potato chips brand. The goal was to create a bold food-product layout with a clear product focus, flavour details, call-to-action buttons, and a featured flavours section.

I wanted the page to feel colourful and energetic while still keeping the product information easy to scan.

## What I built

- A navigation bar with a logo, menu links, and search area
- A main product section with heading, product image, description, cart button, and quantity selector
- Product highlights for natural ingredients, oven grilling, and taste
- Flavour cards with icons and short descriptions
- A footer section that displays featured chip flavours as product cards

## Skills I used

- **HTML structure** — I used sections such as `header`, `main`, `section`, and `footer` to organise the page.
- **CSS Grid** — I used Grid to divide the page into the header, main content area, and footer.
- **Flexbox** — I used Flexbox to align navigation items, buttons, flavour cards, and footer content.
- **Positioning** — I used relative and absolute positioning to place the main product image and the images inside the flavour cards.
- **Spacing and layout** — I adjusted margins, gaps, padding, and grid row sizes so the footer has more breathing room and the layout feels less crowded.
- **Styling details** — I worked with colours, rounded corners, shadows, borders, icons, buttons, and typography to give the page its look.

## What I learned

While building this project, I learned that small spacing changes can make a big difference to a design. I improved my understanding of when to use Grid for the main page layout and Flexbox for aligning smaller groups of elements.

I also learned how absolute positioning can help place an image exactly where I want it, but it needs to be used carefully so it does not clash with other content. Working on the footer helped me practise balancing card sizes, image placement, and empty space in one section.

Most importantly, this project gave me more confidence in turning a visual idea into a real webpage using only HTML and CSS.

## Built with

- CSS3

## How to run

1. Download or clone this project.
2. Keep the image files inside the `image` folder used in the HTML.
3. Open the HTML file in your browser.
